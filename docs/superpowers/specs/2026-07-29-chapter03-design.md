## 章节定位

第三章是“承”的起点。它不再追问单张残页写了什么，而是让玩家第一次系统追查材料如何在官署、私人藏家、书坊、寺院和舟行经手人之间流动。

运行时元数据固定为：`id: "chapter03"`、`title: "第三章"`、`subtitle: "半印相合"`、`date: "康熙九年 · 九月下旬"`、`place: "岭南水路 · 肇庆方向"`、`weather: "秋雨断续"`。具体行程日数必须通过研究门；若来源不支持精确日程，正文只使用“次日”“数日后”等相对时间，不制造公历或农历精确日期。

章节命题是：两份材料在传播链上相遇，不代表两份文字彼此证明。玩家能够确认经手、载体和转移关系，却仍须把作者、内容真伪和沈掌柜动机保留为待查。

章节结束时，所有路线进入肇庆共同主线，但以下差异继续保留：

- 旧志或夹页原件仍在玩家／书坊控制下；
- 玩家只有自己制作的副本；
- 原件由修志局控制；
- 原件由陌生藏家控制；
- 原件已经交还周家。

## 章节结构

### 第一幕：处置前导与入口劳动（单次游玩 20%）

每个入口都让玩家先处理自己选择造成的现实条件：没有原件就核副本来源，材料在官方手中就查登记程序，材料被卖就追交易记录，材料交还则通过关系换取有限访问。

开场不重复介绍第二章，而是通过桌面上“有哪些东西不在场”显示后果。玩家完成一次查验或比对后，获得进入所属宏观路线的具体线索。

### 第二幕 A：广州版本链（选择该线时占单次游玩 50%）

核心劳动是制作版本谱系：把旧志、净稿、秘密副本、删稿登记、售书记录或私人抄本按“文本层—载体—经手人—日期范围”排列。

广州三个入口会改变可填入的证据格：

- 官方入口能看到程序和卷号，但关键旧文本可能不可见；
- 私抄入口能比较异文和题跋，但缺少官方删改理由；
- 藏家入口能看到市场传播，却无法保证材料长期可复查。

路线结论只能是某段文字在至少两个版本层出现、某次删改发生于两个可界定阶段之间，或某份副本来自主角自己的摹写。不得由版本数量推出历史事实已经证实。

### 第二幕 B：南海传播链（选择该线时占单次游玩 50%）

核心劳动是重建经手链：通过针孔、蓝线、水痕、折痕、半印和题签判断材料是否曾被同一批装订、拆分或转运；随后把梁老人、周家转述和寺院经手人的话按见证层级著录。

西樵入口先查物证再问人；肇庆半印入口先查本地收件记录，再反向确认西樵题签。两种开场在中段得到相同的“传播链可能相接”问题，但携带的原件、关系和可复查程度不同。

寺院人物不得成为庚寅之劫的方便全知见证者。即使其年龄足够，也只陈述自己实际经手过的纸、当时听到的话和后来形成的寺内传承。

### 第三幕：肇庆汇合（单次游玩 30%）

两条宏观路线最终抵达同一处虚构的肇庆旧书交接点。玩家把路线所得的半印、递送题签或经手记录与第一章缺页清单并置。

共享劳动包含：

1. 拼合半印／纸边，判断它们是否属于同一交接标记。
2. 比对卷号、纸数和经手日期范围，确认两条材料链曾在同一批次或同一中介处相遇。
3. 在长编中选择把该结论收入正文、附录或存疑，并写明仍不能证明的内容。

正确的最强结论是“现有物证支持两条材料传播链曾在肇庆的某个交接点相遇”。以下结论一律判为越界：两份正文互相证明、半印证明原作者身份、经手人策划了全部传播、沈掌柜已经知道完整真相。

章末通过 `ch03-zhaoqing-convergence` 进入唯一终点 `ch03-ending-zhaoqing`，并解锁第四章共同准入 ID `zhaoqing-common-ledger`。第四章尚未实现时，该终点只提供章节笺记与舆图安全出口，不包含失效跨章跳转。路线来源、史料处置、工钱、风险、人物信任和可复查物证差异继续保留。

## 材料设计

第三章固定增加五份运行时材料，并由故事数据测试保证 ID 唯一：

- `gazetteer-deletion-register`：修志局删稿登记，只在官方入口直接取得。
- `panyu-early-copy`：番禺更早抄本，只在私人传抄入口直接取得。
- `collector-sale-docket`：藏家转手收条，只在陌生藏家入口直接取得。
- `xiqiao-copy-register`：西樵针孔同式誊稿及经手题签，在西樵入口取得；肇庆半印入口只能得到其引文或后续目验记录。
- `zhaoqing-transfer-tally`：带半印的肇庆交接记录，是两条宏观路线都能取得的汇合材料；它只支持经手关系。

所有材料必须填写来源人物、发现地、年代范围、载体、纸墨笔迹、标记、风险、传播状态、建议解释和缺失旁证。入口缺失的原件不得在材料目录中以“重新获得”出现；只能登记副本、引文、目验记录或交易回声。

本章固定新增三个档案 ID：`chapter03-version-lineage`、`chapter03-transmission-lineage`、`chapter03-zhaoqing-convergence`。广州线只解锁第一项，南海线只解锁第二项，两线都在共享劳动后解锁第三项。

## 人物边界

- 沈掌柜继续只知道部分经手关系，不在本章解释自己为何认识残页。
- 县署书吏可以说明当前修订流程，不能代表全部官署意见，也不知道陌生客身份。
- 陌生客仍是材料买家／中间人，第三章不揭示最终雇主或把他升级为幕后首脑。
- 西樵誊稿僧为明确虚构人物，1670 年至少 53 岁；其 1650 年所在地、经手时间和见证层级必须在 `CHARACTERS.md` 固定。法号仍只确认包含“澄”字，第三章不靠完整姓名制造答案。
- 番禺抄本持有人和肇庆经手人保持职业性称谓；匿名是材料传播风险的一部分，不作为未完成设定。

## 研究门

写正文前必须形成窄范围研究简报，并在 `docs/research/CLAIMS.md` 登记实际采用的断言：

1. 1670 年广州、番禺、西樵、肇庆之间可使用的水路与行程表达。
2. 清初封签、私印、收条、递送簿的形制及其能够／不能够证明的范围。
3. 地方志纂修、分卷誊抄、删稿与旧稿保存的时代依据；无法补证的部分明确降为 H3/H4。
4. 西樵一带寺院与僧侣誊写网络；若使用真实寺名、法号或制度，逐条核对原始文献或正式研究。
5. 半印吻合、匿名经手人与具体材料链统一登记为 H4 合成情境。

OCR、用户旧论文与 AI 产出只用于定位。H1/H2 必须回到母库中的 S1/S2 来源和具体页码；研究未过门时，相关对白不得进入正式故事 JSON。

## 失败与边界处理

- 停在上述八个已知 ending beat 的旧存档即使缺少 `unlockedEntrances`，也按 ending ID 唯一映射到对应处置前导，并在进入时幂等补登记入口；未知 ending、非法 beat 或无法唯一映射的存档才停留在安全出口，不猜测默认路线。
- 已售、已毁、已交还或入署的原件若被入口数据错误地重新授予，故事数据测试必须失败。
- 任一路线都必须存在可达终点；汇合不能覆盖玩家已保存的编纂状态。
- 新增 H1/H2 断言处于 `unreviewed` 或 `rejected` 时，第三章不能进入发布候选。

## 验收标准

- 八个第二章结局均可进入各自处置前导，五个入口劳动分别可达，且都有独立发现与后果反馈。
- 三个广州入口收束为版本链，两个南海入口收束为传播链，两条路线在肇庆共享劳动后汇合。
- 章末共同方向一致，但材料控制权、可靠性、风险、工钱和人物信任差异没有被抹除。
- 玩家至少完成一次查验／比对、一次传播或版本关系判断、一次长编取舍。
