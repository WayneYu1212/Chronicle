## 实现范围

### 地图与可访问性

- `.map-location` 的最小可交互尺寸为 44×44px；视觉红点可以小于命中区域。
- 不移动既有六个红点中心，除非当前底图复核证明坐标偏离。
- 桌面、窄屏和 200% 缩放下，地点标签不得遮挡选中地点的核心信息；信息栏必须能完整滚动。
- 地图按钮、手札入口、抽屉关闭、长编输入和处置按钮必须有可见焦点及完整键盘路径。
- 触摸目标放大不能改变地图底图、地点名称或叙事状态。

### 依赖升级

- `next` 与 `eslint-config-next` 同步锁定到 15.5.21；React、TypeScript 与其他依赖不借机升级。
- 不使用 `npm audit fix --force`。
- 升级后若 npm audit 因网络失败，记录命令、时间和错误，并保持 `YS-P2-05` 与 P2 阶段未完成；不得把旧审计结果伪装成新结果。只有创始人书面接受该项安全残余风险时，才可带例外过门。
- 生产构建使用隔离副本，避免把当前工作区 `.next` 文件锁误判为源码失败。

### P2 验收包

新增 `docs/qa/P2-DEMO-ACCEPTANCE.md`，固定记录：

1. 源码提交或工作树标识、依赖版本与测试命令；每项证据记录日期、执行人、附件相对路径和复测状态。
2. Chromium、Firefox、iPhone Safari、微信内置浏览器的版本、设备、路径、结果和证据位置。
3. 200% 缩放、完整键盘、窄屏单页、横竖屏、减少动态效果和地图六点专项。
4. 五名目标玩家的匿名编号、是否属于目标玩家、是否参与开发、任务结果与访谈摘要。
5. PRD 成功指标：至少 4/5 区分材料／解释／传播史，至少 4/5 发现非对白证据，至少 4/5 理解不可逆选择。
6. 阻断缺陷、修复复测、非阻断风险及 Android Chrome 未验证声明。
7. QA 总监、独立审查总监与创始人的最终结论。

同一候选构建还要执行时间轴专项：卷首、首页、游戏扉页、手札默认日期、第一／二／三章元数据、当年形成的史料元数据、人物年龄与“距庚寅之劫二十年”必须统一为康熙九年（1670）。不得把 1650、1653、顺治七年等史料自身年份改成 1670。

存档端到端路径使用同一候选构建逐项记录：新游戏写入、刷新恢复、卷首继续游戏、导出原始存档及其保留说明、清档后回到新游戏、损坏存档恢复页、未来版本存档拒绝覆盖，以及 localStorage 写入失败的可见提示。本轮不新增存档导入功能。清档测试前必须先导出测试存档，不使用用户的真实浏览器存档作为破坏性样本。

玩家研究只保存匿名行为与访谈结论，不收集无关个人信息。Agent 评审、自动浏览器脚本和开发者自测不能计入五名目标玩家。

## 数据流与失败处理

- P2 不改变故事 JSON 契约或存档 schema。
- UI 修复继续读取现有 `unlockedLocations`、`investigatedLocations`、编纂状态与偏好设置。
- localStorage 被拒绝、存档损坏、未来版本存档和写入失败必须继续显示既有可恢复提示。
- 浏览器或网络不可用时，验收项保持未执行，并记录具体阻断；不得用 Chromium 结果替代 Firefox 或真机结果。

## 工作树保护

- 当前 `main` 工作树包含大量用户变更与 `.next` 生成物；只对目标文件做定点补丁。
- 不执行 `reset`、`clean`、批量格式化、全量暂存、提交、推送、部署或构建产物删除。
- 修改前后保存目标文件的逐文件 diff；隔离构建不得回写或覆盖工作区缓存。

## 验收标准

P2 只有在以下条件全部满足后才能由创始人批准过门：

- `YS-P2-01—06` 均具有对应证据；Android Chrome 可保留为明确的非阻断未验证风险。
- 目标浏览器与真实 iPhone／微信主流程无阻断缺陷。
- 地图六点、44px 触控、键盘、200% 缩放及信息栏滚动通过。
- 当前产品真相与玩家可见时间轴统一为康熙九年（1670），人物年龄、出生年和 1650 年事件年龄算术一致；正常旧存档加载后使用当前史料目录的 1670 元数据并保留玩家判断与处置。
- 新游戏、继续、刷新、导出、清档、损坏／未来版本恢复及写入失败路径具有端到端证据。
- 五名目标玩家完成测试，三项核心理解指标均达到至少 4/5。
- 15.5.21 升级后的测试、lint、TypeScript 与隔离生产构建通过，并成功取得升级后的新 audit 结果；网络失败默认阻断，除非创始人书面接受该项安全残余风险。
- QA 总监给出 `approve`，独立审查给出 `pass`，创始人书面批准 Demo。

在真实玩家、真机或 Firefox 证据缺失时，可以完成代码与验收包，但 P2 状态仍为“进行中”。
