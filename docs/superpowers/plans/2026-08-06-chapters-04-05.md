# Chapters 04-05 Integration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Integrate the supplied Chapter Four and Chapter Five story package into Chronicle, make every supplied activity playable, preserve prior chapter saves and irreversible evidence states, and leave the existing mobile onboarding task verified.

**Architecture:** Treat the supplied JSON files as the narrative source of truth. Extend the shared story contract with data-driven activity configurations, route-choice updates, top-level fragment actions, and the package's custody states. Keep activity UI in focused components selected by `ActivityStage`; components return `ActivityResult` and never write saves directly. Merge only new fragments/archives and the package's updated location records into the existing catalogs.

**Tech Stack:** Next.js 15.5.21, React 19, TypeScript 5.7, CSS, Node test runner via `tsx`, browser localStorage.

## Global Constraints

- Story facts remain in `src/story/*.json`; React components contain no new chapter facts.
- Preserve old Chapter One–Three beat IDs, old save fields, permanent disposition semantics, and existing tutorial/mobile changes.
- Chapter Four has 109 beats and Chapter Five has 185 beats; all supplied beats must be registered and reachable from the existing Chapter Three convergence.
- Support click/touch controls for every activity; drag interactions may be an enhancement, never the only path.
- Keep the existing paper, book-shell, Chinese font fallback, reduced-motion, and static-export constraints.
- Do not add runtime dependencies, backend state, or a new save schema unless tests prove a migration is required.
- Do not stage `.next`, `out`, `tsconfig.tsbuildinfo`, logs, shortcuts, or unrelated user files.
