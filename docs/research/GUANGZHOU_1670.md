# 康熙九年（1670）广州生活与语言素材基线

状态：v1.1。适用于广州城及珠江水网场景。主参考为康熙木天阁版《广东新语》；它记录晚明至清初广东见闻，但仍须区分“词物可证”和“1670 某日必然如此”。

## 可考词语与语言策略

《广东新语》“土言”条可证当时记录者收录：爸、嬭、阿／亚作前缀、估、挪、捺、搲、够／不够、邋遢、鼻齆、龅牙、打边炉、打灯等（PDF 第217页／书页195）。同条网络文本还见“靓”“硬颈”“古气”等释义。

“有记录”不等于适合大量写进对白：词义、语音、阶层、场合与今天可能不同。正式文本继续使用简体中文和普通话式现代可读表达，只在不妨碍理解时嵌入一个已核词。

- 每场最多突出一个地方词，由上下文自然释义，不设方言考试。
- 地域感优先来自雨、潮、舟、饮食、劳动节奏和城市方位。
- 小满可在骤雨时说：“白撞雨，偏会挑忙时撞进来。”其中词语有时代文献依据，整句是剧情对白，不冒充史料原句。
- 船夫先谈潮和湿气，书坊人先关心纸墨受潮，食肆人物才谈糖与吃食；细节服从职业视角。
- 若使用原文粤歌或更强口语，须另立史料卡，核对版本、年代、场合和释义。

## 暂不使用或须另证

- `佢、冇、喺、咗、嘅、哋、啱、搞掂、收工、打工、靓仔、点解、唔该` 等现代常见粤语写法：当前资料未证明其在 1670 的同形、同义、同场合用法。
- 不用现代句末助词堆叠模拟“古代广东话”。
- “佣书按件／按字计价”“逢五日结钱”“赊米”等行业制度当前仅属设计假设，不能标成广州史实。
- 避免把十八世纪十三行、一口通商制度、近现代茶楼饮早茶习惯前置到 1670。
- “澳门人的记录”须注明作者、写作时间、所在地、语言、报告形成与后出译抄关系；澳门编成或转递，不等于作者在澳门目击广州事件。
