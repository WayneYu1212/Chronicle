# 《佣书》历史内容证据台账

状态：P0 基线已完成首轮系统审校；新增或改写断言仍须逐项登记

状态口径：`supported` 表示断言的历史、推断、设计或虚构分类及其使用边界已经审校；对 H3/H4 而言，不表示职业体验或虚构内容本身获得了历史来源支持。

外部研究母库：按 `SOURCE_LIBRARY.md` 中的唯一根路径定义

本台账记录玩家可能理解为现实历史陈述的内容。它不改变游戏内“材料可能不可靠”的设计，而是保证制作团队知道每句话在现实研究层面的依据。

## 字段

| 字段 | 含义 |
|---|---|
| ID | 稳定的 `HIST-###` 标识 |
| 位置 | 文件与节点／史料 ID |
| 摘要 | 需要审校的现实历史断言 |
| 类别 | H1 可核查史实、H2 来源支持推断、H3 设计推断、H4 明确虚构 |

| 书目信息 | 作者、题名、出版／版本信息 |
| 母库相对路径 | 相对 `SOURCE_LIBRARY.md` 根路径的文件位置 |
| 定位 | 页码、卷次、条目或其他稳定定位 |
| 研究备注 | 推理链、替代解释及游戏化处理 |
| 状态 | `unreviewed`、`supported`、`contested`、`rejected` |
| 关键／争议 | 是否要求两条或更多独立来源链 |
| 审校 | 审校者、日期与独立来源链数量 |

## HIST-001—005 详细来源与边界

### HIST-001

- 书目信息：董少新，《曾德昭〈鞑靼人攻陷广州城记〉译注并序》，《海洋史研究》第十九辑，社会科学文献出版社，2023年11月，第254—269页。
- 母库相对路径：`史料/曾德昭《鞑靼人攻陷广州城记》译注并序_董少新.pdf`。
- 定位：刊物第262—263页；PDF第9—10页；脚注5、6把报告的“那天／第二天”分别注作11月24日、25日。
- 游戏取文：残页依次截取“第二天”“下午前往城墙那边”“聆听告解一直到五点多钟”和男仆示警短句；省略号明确这些不是连续全文。译文依据刊物第262页／PDF第9页。
- 风险说明：同一作者2024年论文第31页将城墙边告解与示警概括为11月24日，与详细译注的相对日序不完全一致。游戏不把任何精确公历日写成报告正文；公历日只可作为后出注释或研究争议出现。
- 来源链要求：此处证明的是“曾德昭报告如何记述”，单一见证来源即可；若要把精确日历日期作为客观事实，必须补独立历法／原文校勘链。

### HIST-002

- 书目信息：董少新，《1650年广州“庚寅之劫”——原始文献与历史记忆》，《新史学》第35卷第4期，2024年12月。
- 母库相对路径：`史料/1650年廣州「庚寅之劫」──原始文獻與歷史記憶.pdf`。
- 定位：PDF／文内第3页概述城陷与伤亡；第15页转录《平南王元功垂范》攻城、死伤与入城叙事；第44页讨论三类原始文献的互补与局限。
- 边界：游戏“旧志”不是任何真实方志的转录；不得加真实书名、卷次、作者或“原文曰”。

### HIST-003
